SHOPEASY - ONLINE SHOPPING WEBSITE (STUDENT PROJECT)

FILES
1. index.html  - Website structure and pages/sections
2. style.css   - Website design and responsive layout
3. script.js   - Product search, filters, cart and demo checkout

HOW TO RUN IN VS CODE
1. Extract the ZIP folder.
2. Open the folder in Visual Studio Code.
3. Open index.html.
4. Right-click inside the file and choose "Open with Live Server".
   If Live Server is not installed, install the Live Server extension.
   You can also double-click index.html to open it in a browser.

FEATURES
- View sample products
- Search by product name
- Filter by category
- Filter by maximum price
- Add products to cart
- Increase/decrease quantity and remove products
- Checkout form
- Cash on Delivery and demo online payment selection
- Order confirmation screen
- Cart and demo orders stored in browser localStorage

IMPORTANT LIMITATIONS
This is a front-end student demonstration. The online payment option does NOT charge money.
No real emails are sent. Real online payments and email notifications require a secure backend,
database, payment gateway and email service. Do not collect real customer payment details in
this demo. Product/order data is stored only in the current browser.
